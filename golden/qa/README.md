# Состязательный прогон по флоу

Тесты отвечают на вопрос «работает ли то, что мы написали». Эти три
прогона отвечают на другой: «не врёт ли одно другому и цел ли путь,
которым ходит человек». Они находят то, чего юнит-тест не видит по
устройству, — расхождение документов между собой, русское слово внутри
графики, пункт меню без действия.

```bash
pnpm tsx golden/qa/sweep.ts        # категории × языки × посадки × границы
pnpm tsx golden/qa/consistency.ts  # не врут ли документы друг другу
./golden/qa/cabinet.sh             # кабинет целиком, при поднятом demo:server
```

`cabinet.sh` ждёт сервер на 8132 и демо-инвайт: 

```bash
PORT=8132 DATA_DIR=apps/web/data WEB_DIST=apps/web/dist pnpm demo:server
```

Все три печатают «найдено проблем: N» и перечисляют находки. Ноль — не
повод не смотреть глазами: прогон проверяет то, о чём мы догадались
спросить.

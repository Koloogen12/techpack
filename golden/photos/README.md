# Эталонные фотографии голден-набора

Четыре снимка трикотажного ядра: футболка, лонгслив, свитшот, худи.

## Откуда они

Сгенерированы Nano Banana Pro через Higgsfield специально под требования
пайплайна — и специально с исправлением того, на что модель разбора
жаловалась на первой реальной фотографии:

| Жалоба на первом снимке | Что сделано здесь |
|---|---|
| «Изделие подано в манекенном виде без плоской раскладки» | разложено плоско, съёмка строго сверху |
| «Чёрное на белом: детали конструкции теряются в тенях» | средние тона, мягкий рассеянный свет |
| «Число параллельных строчек достоверно не подтверждено» | строчки, манжеты и пояс различимы |
| «Масштабного объекта в кадре нет» | не исправлено — масштаб приходит от пользователя, это свойство продукта |

## Чем они являются и чем не являются

**Являются** воспроизводимым входом для проверки пайплайна: категория
опознаётся, пропорции извлекаются, узлы подтверждаются, документ собирается.

**Не являются** проверкой точности. У этих изделий нет настоящих замеров —
их пропорции такие, какими их нарисовала модель. Пайплайн честно передаёт
то, что видит на снимке, и если снимок показывает изделие непривычных
пропорций, документ это повторит.

Сантиметры проверяются только сравнением с рулеткой на реальных вещах.
Это вход В2 из `DEV-PLAN.md`, и он остаётся открытым.

## Живые отчёты разбора

В `../vision-reports/` лежит настоящий выход модели на этих снимках —
не выдуманные данные. Они коммитятся, поэтому голден-набор гоняется в CI
без ключа API и без сети, но проверяет настоящую ветку кода.

Пересобрать после прогона с ключом: `pnpm golden:export`.

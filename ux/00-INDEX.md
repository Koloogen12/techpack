# Seamster — UX-пакет: индекс и трассировка

> v1.0 · 2026-07-16 · комплект для команды и Claude Design
> Состав: `00-INDEX` (этот файл — карта + трассировка разведки) · `01-cjm-userflows.md` (CJM + 12 флоу) · `02-screens-spec.md` (структура каждого экрана) · базовые токены и правила стиля — в `../UI-SPEC-app.md` §1

## Как скармливать Claude Design (порядок)

1. `../UI-SPEC-app.md` §0–§1 (принципы + стиль) — контекст всегда первым.
2. `01-cjm-userflows.md` — флоу того модуля, который проектируем.
3. `02-screens-spec.md` — раздел конкретного экрана.
4. Задание: «спроектируй экран X по спеке, стиль по §1, проверь по стиль-тесту из UI-SPEC §8».
Волны: (1) Мастер + Генерация + Замеры + Чертёж → (2) Дашборд + Экспорт → (3) BOM + Конструкция + Ярлыки → (4) Версии/Примерки + Библиотека + Тариф.

## Трассировка: разведка конкурента → наше решение → где в спеке

| #   | Слабость конкурента (из 21 ответа + их схемы)                                                 | Наше решение                                                                                                     | Где                               |
| --- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| 1   | Замеры от «дефолтного M системы», пользователь правит всё сам                                 | Якорь от пользователя: размер + рост + посадка в мастере; расчёт от сеток ГОСТ + пропорций фото                  | F1 шаг 2; экран «Мастер»          |
| 2   | Допуски не ставятся вообще («критично, ставьте сами»)                                         | Автодопуски по классам точек + глобальный дефолт таблицы + override на строку (их же паттерн из схемы — забрали) | Экран «Замеры»                    |
| 3   | Градации нет, «правила — ваша тайна»                                                          | Автоградация типовыми приращениями RU + редактируемые приращения (Pro)                                           | Экран «Замеры»; F3                |
| 4   | Нет пометок уверенности — «всё считайте черновиком»                                           | 4 статуса уверенности на каждом значении + сводка «подтвердить по образцу»                                       | Сквозной паттерн; все экраны      |

| 6   | Их список «что фабрики просят исправить» (замеры, допуски, конструкция, BOM, fit-комментарии) | Каждый пункт списка = наш модуль со встроенным решением                                                          | Все модули Workspace              |

| 8   | Невидимое с фото подставляется молча общими стандартами                                       | Явный `assumption`-статус + блок «уточнить у фабрики/по образцу»                                                 | Экран «Конструкция»; F6           |
| 9   | Нет кодов швов ISO, SPI, машин — «впишите вручную»                                            | Коды ГОСТ=ISO + SPI + машина на каждой операции (Pro-режим)                                                      | Экран «Конструкция»               |

| 11  | Флэты не редактируются — перегенерация или SVG→Illustrator                                    | Параметрический SVG: правка данных меняет чертёж                                                                 | F3, F4; экраны «Замеры», «Чертёж» |

| 13  | Версий нет — «дублируйте проект и называйте V2»                                               | Версии + примерки (fit comments) как модуль                                                                      | F9; экран «Версии»                |
| 14  | Расход не считают («невозможно без лекал»)                                                    | Предварительный расход по формулам с пометкой «уточняется фабрикой»                                              | Экран «BOM»                       |
| 15  | Colorway — строка, BOM один на все цвета                                                      | Сущность colorway: BOM и SKU на каждый цвет                                                                      | Экран «BOM»; F10                  |
| 16  | Экспорт PDF + плоский SVG без слоёв                                                           | PDF полный + по ролям цеха; SVG послойный; DXF-passthrough                                                       | Экран «Экспорт»; F8               |
| 17  | Маркировки/локальных норм нет                                                                 | Модуль «Ярлыки»: ТР ТС, символы ухода, SKU под Честный знак                                                      | Экран «Ярлыки»; F7                |
| 18  | Слабые категории (подкладка, бельё) не гейтятся — просто хуже результат                       | Категорийный гейт: вне MVP-категорий — честный отказ + waitlist категории                                        | F1 шаг 1                          |
| 19  | Human review нет вообще                                                                       | QA-слой v0.1 (concierge) + опция «проверка технологом» как платная услуга позже                                  | F2                                |
| 20  | Кредиты, саппорт «не обещаем сроков»                                                          | Списание только за успех, бесплатный повтор, видимый SLA поддержки                                               | Экран «Тариф»; F11                |
| 21  | Вход: изображения + тип + ткань + цвет                                                        | Берём и расширяем: + размер/рост, посадка, размерный ряд (5 вопросов)                                            | F1                                |

**Их паттерны, которые мы забрали:** допуск-дефолт таблицы + override на точку · мини-диаграмма «как мерить» у каждой точки · референс-фото хранятся в паке · кредиты за успех · вопросы тип/ткань/цвет на входе.

## Термины интерфейса (обязательный словарь UX-писателя)

техпак · замеры (не POM в UI для новичка; «POM» появляется в Pro) · допуск · размерный ряд · посадка · материалы (BOM в Pro) · узлы обработки · техпоследовательность (Pro) · примерка образца (не fit comment) · просчёт (не квота) · «подтвердить по образцу» · статусы: «указано вами / оценка по фото / типовое значение / предположение»

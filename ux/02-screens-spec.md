# SpecForm — детальная структура экранов

> v1.0 · 2026-07-16 · формат каждого экрана: назначение → зоны и элементы → состояния → взаимодействия → edge cases. Стиль и токены: `../UI-SPEC-app.md` §1. Флоу: `01-cjm-userflows.md`.

---

## Э1. Auth

**Назначение:** вход за ≤30 сек, ноль трения.
**Зоны:** центр-карточка: лого · заголовок «Техпак из фото» · поле email · кнопка «Получить код» → поле кода (6 цифр, автосабмит) · юр-строка.
**Состояния:** ввод email → ввод кода → [неверный код: инлайн + повтор через 30с] → [письмо не пришло: «отправить снова» + проверить спам] → успех.
**Edge:** deep-link из лендинга с utm — сохранить для аналитики сегментов.

## Э2. Dashboard (проекты)

**Назначение:** возврат в работу за 1 клик; для новичка — единственная дорога в мастер.
**Зоны:**

- Шапка: лого · поиск · баланс кредитов (чип) · профиль.
- Тулбар: «+ Новый техпак» (главный CTA) · фильтр статуса · фильтр категории.
- Сетка карточек техпака: превью флэта (мини-SVG) · название · категория · статус-бейдж (черновик / генерация / проверяется технологом / готов / на просчёте / версия N) · дата · меню (дублировать · переименовать · удалить · экспорт).
  **Состояния:** [empty — первый вход] hero-карточка на всю ширину: иллюстрация «фото → документ», Н2 «Создай первый техпак из фото», подзаголовок «≈7 минут, поможем на каждом шаге», CTA. Ничего больше. · [генерация идёт] карточка с живым прогрессом · [черновик] «продолжить с шага N».
  **Edge:** удаление — soft-delete с undo-тостом 10 сек; дублирование копирует StyleSpec без версий/примерок.

## Э3. Мастер создания (обёртка F1)

**Назначение:** собрать входы для генерации, не потеряв новичка.
**Зоны:** прогресс «шаг N из 3» · тело шага · навигация (Назад / Далее) · автосохранение-индикатор.
**Шаг 1 — Фото:** дропзона (плитки-превью 1–6, star = главное фото) · подсказка качества («ровный ракурс = точнее чертёж», примеры хорошо/плохо по ховеру) · [предупреждение качества per-файл].
**Шаг 2 — Вопросы (5 карточек, вертикальный скролл):**

1. Категория: чип-подтверждение автоопределения + сетка категорий [вне MVP → гейт-карточка waitlist категории].
2. Размер+рост: два селектора с двойной шкалой (46/M · 170); «почему спрашиваем: от этого считаются все сантиметры».
3. Посадка: 4 карточки-силуэта с мини-иллюстрациями; выбранная — обведена.
4. Материал: чип-подтверждение (трикотаж/ткань) + опциональная плотность (селектор «не знаю» — дефолт).
5. Ряд+тираж: чипы размеров (мультивыбор, базовый помечен) · поле тиража.

- Аккордеон «Повысить точность» (свёрнут): фото с предметом-референсом · один ручной замер.
  **Состояния:** валидация per-карточка; кнопка генерации активна при минимуме (фото + категория + размер).
  **Edge:** возврат к шагу 1 после ответов — ответы сохраняются; смена категории — предупреждение «вопросы обновятся».

## Э4. Генерация (F2)

**Назначение:** удержать 2–5 минут ожидания и подготовить Aha.
**Зоны:** центр: анимация этапов (5 стадий с чек-марками) · ETA · под ней карусель фактов («допуски по классам точек — как в приёмке ОТК») · кнопка «свернуть» (генерация продолжается, на дашборде прогресс).
**Состояния:** успех → авто-переход в «раскрытие документа» (обложка → чертёж → таблица замеров, 3–4 сек анимации, пропускаемо) → Workspace · частичный успех → Workspace с помеченными зонами · ошибка → карточка: причина человеческим языком · «Повторить бесплатно» · «Написать нам (ответ до N часов)».
**Edge (v0.1 concierge):** стадия «проверяется технологом» с честным сроком; уведомление по готовности.

## Э5. Workspace — обёртка

**Назначение:** дом документа; навигация по 7 разделам без потери контекста.
**Зоны:**

- Шапка: ← к проектам · название (инлайн-редакт) · статус/версия (чип «v2 · после примерки №1») · автосейв-индикатор · переключатель Pro · [Экспорт] · [На просчёт →] (акцентная).
- Лево: вертикальные табы-разделы: Обзор · Чертёж · Замеры · Материалы · Конструкция · Ярлыки · Версии. Бейджи на табах: число предположений (⚠2) — куда смотреть.
- Центр: контент раздела.
- Право: контекстная панель выбранного элемента (детали, статус уверенности, «откуда это значение», связанные элементы) [пусто → подсказка раздела].
  **Сквозное:** глобальный фильтр «показать только предположения» (тумблер в шапке) — во всех таблицах остаются только ⚠-строки.

## Э5.1. Обзор (cover)

**Зоны:** карточка стиля (название, артикул авто, категория, сезон, базовый размер, ряд, посадка, материал — всё редактируемо) · референс-фото (карусель, «главное») · мини-превью чертежа · **сводка честности**: «34 рассчитано · 6 подтвердить по образцу → смотреть» (клик = глобальный фильтр ⚠) · colorways-строка (+ добавить цвет).
**Edge:** смена базового размера здесь — глобальный пересчёт с подтверждением.

## Э5.2. Чертёж (F4)

**Зоны:** канвас SVG (перед/спинка табы, зум 25–400%, пан, fit) · панель слоёв (5 чекбоксов) · правая панель: выбранный элемент → узел/материал со статусом.
**Взаимодействия:** клик элемента ↔ подсветка строки; двусторонняя связь с «Конструкцией»; «На фото не так» → диалог замены элемента (сетка вариантов узла) → перегенерация узла.
**Состояния:** [перестроение после правки] плавная анимация ≤1 сек + флеш-подсветка изменённой зоны.
**Edge:** элемент без связи (декор) — панель показывает «декоративный элемент, в конструкции не участвует».

## Э5.3. Замеры (F3) — самый важный экран

**Зоны:**

- Тулбар: базовый размер (чип) · допуск-дефолт таблицы (редактируемый, «±1,0 см — стандарт для трикотажа») · «пересчитать градацию» · фильтр ⚠ · [Pro: приращения].
- Таблица: код (Pro) · точка (рус., ховер = мини-диаграмма «как мерить» + текст) · базовое значение (инлайн-редакт) · допуск ± (override per-строка, отличие от дефолта подсвечено) · статус уверенности (чип) · колонки размеров ряда (авто, редактируемые).
- Сплит-вью справа (сворачиваемый): диаграмма замеров — флэт со стрелками и кодами; ховер строки ↔ подсветка стрелки.
  **Состояния:** правка → live-чертёж → статус «указано вами» · значение вне диапазона категории → жёлтое «необычно, проверьте» · [Pro] строка приращений между колонками размеров.
  **Edge:** сброс одного значения к рассчитанному (иконка «↺» при статусе «указано вами») · добавить свою точку (Pro) — из справочника точек категории.

## Э5.4. Материалы (F5)

**Зоны:** colorway-переключатель · группы (основное полотно / фурнитура / нитки / прокладки / упаковка) · таблица: позиция · описание · состав/плотность (селекторы) · цвет (Pantone-чип + «сверить по выкрасу») · расход (+ пометка «предварительно») · статус · источник (справочник/библиотека/вручную).
**Взаимодействия:** замена полотна трикотаж↔ткань → модал «затронет 4 узла конструкции: …» с подтверждением · «сохранить в библиотеку бренда» на строке.
**Edge:** позиция-«assumption» (прокладка, невидимая с фото) — всегда ⚠ + строка в «уточнить у фабрики».

## Э5.5. Конструкция (F6)

**Зоны:** зоны изделия (аккордеоны: горловина / плечи и бока / рукава / низ / карманы / застёжка) · внутри — карточки узлов: название простыми словами · описание · [Pro: код шва ГОСТ=ISO · стежок · SPI · машина · припуск] · статус уверенности · флаг «⚙ спецмашина» с CTA «заменить на узел под базовый цех» (диф-превью) · связь-иконка «показать на чертеже».

- Низ экрана: техпоследовательность (Pro): таблица операций №/операция/специальность/оборудование.
- Сайд-блок «Уточнить у фабрики»: автосписок всех допущений конструкции, копируемый текстом.
  **Edge:** замена узла меняет техпоследовательность и BOM (нитки/фурнитура) — показsuch каскад в подтверждении.

## Э5.6. Ярлыки и маркировка (F7)

**Зоны:** три макета-карточки (составник / размерник / навесной) с live-превью · панель данных: юрданные бренда (из профиля, инлайн-дозаполнение) · символы ухода (кликабельные, сетка замен) · состав (из BOM, авто) · SKU-матрица: таблица артикул × цвет × размер, GTIN-плейсхолдеры, экспорт CSV · подсказка «зачем Честный знак» (аккордеон).
**Edge:** несоответствие состава BOM и ярлыка невозможно по построению (один источник) — показать это тултипом «состав берётся из Материалов».

## Э5.7. Версии и примерки (F9)

**Зоны:** таймлайн версий (v1 исходная · v2 после примерки №1 · …) с датами и авторами правок · CTA «+ Примерка образца» · внутри примерки: таблица точка/по спеке/факт/дельта/в допуске (авто-бейдж ✓/✗)/комментарий · фото образца (до 6) · итоговая панель: «5 из 34 вне допуска → Применить правки в новую версию».
**Состояния:** [нет примерок] empty: «Отшили образец? Внесите замеры — соберём правки в новую версию документа» · [Pro] диф двух версий (изменённые значения списком).
**Edge:** применённые правки помечаются «по примерке №1» — статус выше «указано вами» в иерархии доверия.

## Э6. Библиотека бренда

**Зоны:** табы: Материалы · Размерная сетка · Реквизиты и лого. Материалы: карточки с параметрами + «использован в N техпаках». Сетка: таблица тела бренда (перекрывает ГОСТ-дефолты; пометка «влияет на новые техпаки»). Реквизиты: юрформа для ярлыков.
**Состояния:** все пустые состояния объясняют пользу («сохраните один раз — будет во всех техпаках»).

## Э7. Тариф и кредиты (F11)

**Зоны:** баланс крупно · правило списания текстом: «списываем только за успешный техпак; повтор — бесплатно» · тарифы (поштучно/подписка) · бейдж «заказчикам THE MONO — бесплатно» + проверка/связка аккаунта · история списаний (дата · техпак · статус).
**Edge:** пейволл в мастере — до генерации, никогда после заполненных ответов.

## Э8. Настройки

Профиль · уведомления (генерация/просчёты/напоминание о примерке) · Pro-режим по умолчанию · удаление аккаунта (двойное подтверждение, срок хранения данных).

## Приложение А. Иерархия статусов уверенности (сквозная логика)

`по примерке` (максимум доверия) > `указано вами` > `оценка по фото` > `типовое значение` > `предположение` (минимум). Правка повышает статус; перегенерация узла сбрасывает к расчётному; фильтр ⚠ показывает два нижних. В экспорте PDF статусы печатаются легендой на первой странице — фабрика видит карту доверия документа.

## Поверхность 2 — Веб-приложение

```
/app
 ├── /projects                 Дашборд проектов (Э2)
 ├── /new                      Мастер создания: 3 шага (Э3)
 │     └── /generating         Экран генерации (Э4)
 ├── /pack/{id}                Workspace техпака (Э5) — 7 разделов:
 │     ├── overview            Обзор (Э5.1)
 │     ├── drawing             Чертёж (Э5.2)
 │     ├── measurements        Замеры (Э5.3)
 │     ├── materials           Материалы/BOM (Э5.4)
 │     ├── construction        Конструкция (Э5.5)
 │     ├── labels              Ярлыки и маркировка (Э5.6)
 │     └── versions            Версии и примерки (Э5.7)
 │     └── [модалка] export    Экспорт (F8)
 ├── /library                  Библиотека бренда (Э6)
 ├── /billing                  Тариф и кредиты (Э7)
 └── /settings                 Настройки (Э8)
```

| Модуль                     | Одним абзацем (что это и что содержит)                                                                                                                                                                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Дашборд**                | Сетка карточек техпаков (превью флэта, статус: черновик/генерация/проверяется технологом/готов/на просчёте, версия). Пустое состояние = единственная дорога новичка в мастер. Дублирование пака как шаблона — путь повторного использования                          |
| **Мастер**                 | 3 шага: фото (1–6, подсказки качества) → 5 вопросов с «почему спрашиваем» (категория с автоопределением и гейтом вне MVP; размер+рост; посадка 4 карточками; материал; ряд+тираж) + свёрнутый блок «повысить точность» → запуск генерации. Черновики автосохраняются |
| **Генерация**              | Этапный прогресс с реальными стадиями и ETA; кредит списывается только при успехе; повтор бесплатный; ошибки — человеческим языком; v0.1 — стадия «проверяется технологом»                                                                                           |
| **Workspace: Обзор**       | Паспорт стиля (категория, размер, ряд, посадка, материал), референс-фото, мини-чертёж, сводка честности («34 рассчитано · 6 подтвердить»), colorways                                                                                                                 |
| **Workspace: Чертёж**      | SVG-вьювер перед/спинка, 5 слоёв (контур/швы/строчки/фурнитура/выноски), связь элемент↔данные в обе стороны, «на фото не так» → замена узла. Геометрия правится только данными                                                                                       |
| **Workspace: Замеры**      | Таблица точек категории: значение (инлайн), допуск (дефолт таблицы + override), статус уверенности, колонки размеров с автоградацией; мини-диаграмма «как мерить» на каждой точке; сплит-вью диаграммы замеров; правка → live-обновление чертежа                     |
| **Workspace: Материалы**   | BOM по группам и по colorways: состав/плотность/Pantone/расход («предварительно, уточняется фабрикой»); библиотека бренда; каскадные предупреждения при замене полотна                                                                                               |
| **Workspace: Конструкция** | Узлы по зонам: простое описание + (Pro) код шва ГОСТ=ISO, SPI, машина, припуск; machine-park check с альтернативным узлом; автоблок «уточнить у фабрики»; техпоследовательность                                                                                      |
| **Workspace: Ярлыки**      | Составник (символы ухода из материала), размерник, навесной; юрданные из профиля; SKU-матрица (артикул×цвет×размер) с GTIN-плейсхолдерами под Честный знак                                                                                                           |
| **Workspace: Версии**      | Таймлайн версий; примерки образцов: спека/факт/дельта/в допуске + фото; «применить правки» → новая версия; статус «по примерке» — высший в иерархии доверия                                                                                                          |
| **Экспорт (модалка)**      | PDF полный / по ролям (технолог·закройщик·ОТК·снабжение) / SVG послойный; легенда статусов на 1-й странице; шаблон письма фабрике; заглушка лекал с share конструктору; CTA «на просчёт в THE MONO»                                                                  |
| **Библиотека бренда**      | Переиспользуемые материалы, размерная сетка бренда (перекрывает ГОСТ-дефолты), реквизиты и лого для ярлыков                                                                                                                                                          |
| **Тариф**                  | Баланс, правило «за успех», история списаний, тарифы, связка THE MONO=бесплатно; пейволл только до заполнения мастера                                                                                                                                                |
| **Настройки**              | Профиль, уведомления (генерация/просчёты/напоминание о примерке), Pro-режим по умолчанию, удаление аккаунта                                                                                                                                                          |

**Сквозные паттерны приложения:** Pro-режим (плотность, не новые экраны) · статусы уверенности с фильтром ⚠ · автосохранение + undo · пустые состояния всегда с действием · термины с подсказкой при первом появлении.

## Порядок проектирования (для Claude Design)

1. Приложение, волна 1: Мастер → Генерация → Замеры → Чертёж (сердце; там же Aha-«раскрытие документа»).
2. Лендинг (бриф `04`) + страница «Пример техпака».
3. Приложение, волна 2: Дашборд → Экспорт → Обзор.
4. Волна 3: BOM → Конструкция → Ярлыки. 5. Волна 4: Версии → Библиотека → Тариф. 6. Маркетинг-хвост: Тарифы, FAQ, История; SEO-шаблон статьи.

# Кабинет Seamster на общем сервере Hetzner

Продукт живёт на `167.233.109.195` рядом с ContentOS, lovemyage и yoomp.
Машина общая — всё, что делают скрипты этого каталога, ограничено каталогом
`/opt/stacks/seamster`, файлом `/etc/seamster/secrets.env`, своим блоком в
`/opt/caddy/Caddyfile` и сетью `edge`.

    ./deploy/hetzner/deploy.sh              код, сборка, запуск, проверка
    ./deploy/hetzner/deploy.sh --no-build   быстрее: без пересборки образа
    ./deploy/hetzner/caddy.sh               блок домена (идемпотентно)
    ./deploy/hetzner/data.sh pull           снять данные с сервера к себе
    ./deploy/hetzner/data.sh push           залить свои, не трогая серверные

## Чем этот продукт отличается от эталона

**Сервис один.** Ни Postgres, ни Redis: состояние кабинета — каталог файлов
(работы, профили, инвайты, лимиты, рефералы, журнал событий). Поэтому нет и
сети `internal` — прятать от Caddy нечего.

**Том называется `app-files` не случайно.** Общий ночной бэкап ищет базы и нас
бы не увидел, но вторым проходом берёт тома с файлами по маске
`minio|upload|media|files`. Имя `app-files` в неё попадает, и продукт
бэкапится без своего крона. Переименуешь том — бэкап пропадёт молча.

**В образе Chromium.** Не для удобства: кабинет печатает PDF техпака и лист на
просчёт через playwright. Проверить, что он жив после пересборки:

```bash
ssh root@167.233.109.195 'docker exec seamster-app-1 sh -c "cd /app && pnpm --filter @seamster/docgen exec node -e \"require(&apos;playwright&apos;).chromium.launch().then(b=>{console.log(b.version());return b.close()})\""'
```

**Рантайм исполняет TypeScript** через tsx, как кабинет запускался всегда.
Отсюда devDependencies в образе.

## Грабли этого переезда

**`--exclude=versions` в rsync вырезал `packages/versions`.** Пути без ведущего
слеша исключают каталог с таким именем на любой глубине. Пакет workspace
пропал, pnpm оставил симлинк в пустоту, образ собрался, а контейнер упал на
первом импорте. Все исключения теперь якорные.

**`pnpm exec playwright` в корне монорепо не работает.** Бинари вложенных
пакетов не поднимаются в корневой `.bin` — нужен `--filter @seamster/docgen`.

**`RUN a && b && c || true` маскирует провал всей цепочки,** а не последней
команды: сборка «прошла», образ уехал пустым. Шаги теперь раздельные.

**Сервер слушал `127.0.0.1`.** В контейнере это 502 без единой ошибки в логах;
адрес читается из `HOST`, локально по-прежнему петля.

**Проверка «домен отдаёт 308» ничего не доказывает:** Caddy редиректит на https
любой хост, включая несуществующий. Проверять надо контейнер напрямую в сети
`edge`, а маршрут — по https с `--resolve`.

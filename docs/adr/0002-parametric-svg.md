# ADR-0002 — Параметрический SVG: мастер-шаблоны с контрольными точками

**Статус:** принято, чекпоинт по картинке на неделе 2 · 2026-08-25

## Контекст

`CTO-SPEC.md` §5 держит параметрический флэт как инженерный риск №1: «если за неделю флэт не выглядит профессионально → fallback на заготовки с контрольными точками».

Требование рва — R7 и R10 (`TECH-REQUIREMENTS-PIPELINE.md` §5): правка замера обновляет чертёж; флэт редактируется данными, а не перегенерацией. Конкурент недостижим для этих требований, потому что генерирует растр через image-модель и трассирует его.

## Решение

**Фолбэк становится основным подходом.** Каждая категория — мастер-шаблон: набор именованных контрольных точек (HPS, плечевая точка, точка проймы, низ, боковой шов…), между которыми проложены кривые ручного качества. Пропорции из `StyleSpec` двигают точки; кривые следуют за ними.

Обоснование: требование звучит как «правка данных меняет чертёж», а не «геометрия синтезируется с нуля». Мастер-шаблон удовлетворяет R7/R10 полностью и при этом:

- даёт профессиональное качество линий сразу, а не после недель работы с безье;
- новая категория = нарисовать мастер + разметить якоря (дни, не недели);
- элементы (карманы, манжеты, капюшон, планка, кулиска) — библиотека символов, композитятся поверх по `visible_elements`.

Процедурная генерация «с нуля» даёт чертёж, нарисованный программистом. На приёмке у технолога это минус, а приёмка технологом — наша метрика качества (`knowledge-base/07` §6).

**Конвенции линий — жёстко из `knowledge-base/02` §3:** контур 1.5–2pt · конструктивные швы 0.75–1pt · отстрочка пунктиром 0.5pt (число пунктирных линий = числу реальных строчек) · скрытое точками 0.25–0.5pt. Слои: `outline / seams / stitches / hardware / callouts` — послойный SVG, которого нет у конкурента.

**Запрет:** генеративные изображения в технической геометрии — никогда. Допустимы только в маркетинговых превью, отдельным модулем, вне пайплайна.

## Последствия

- Появляется артефакт «мастер-шаблон категории», который надо поддерживать как код (версионируется, тестируется визуальными снапшотами).
- Экстремальные пропорции (oversize +40 см) могут ломать кривые — нужен клэмп якорей и визуальный тест на границах диапазона.

# ADR-0000 — Стек и структура монорепо

**Статус:** принято · 2026-08-25

## Контекст

Команда — один инженер (AI-агент) плюс CEO. Горизонт — 12 месяцев до 1000 платящих. Принцип `CTO-SPEC.md` §1.5: скучный стек, минимум движущихся частей. Бас-фактор закрывается тем, что вся правда лежит в репо.

## Решение

| Слой           | Выбор                                                                                                             | Почему                                                                                                                                                                                                                                   |
| -------------- | ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Язык           | TypeScript, ESM, strict + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes`                               | Один язык от справочников до UI. Типы `StyleSpec` разделяются движком, API и фронтом без дублирования и без кодогенерации.                                                                                                               |
| Версия TS      | **5.9**, не 7.0                                                                                                   | TS 7 (нативный компилятор) уже `latest`, но `typescript-eslint` его не поддерживает — линтер часть CI-гейта, ломать его ради скорости компиляции на старте нельзя. Переход на 7.x — однострочное изменение, как только выйдет поддержка. |
| Монорепо       | pnpm workspaces                                                                                                   | Без Turborepo/Nx: на семи пакетах их оркестрация не окупается.                                                                                                                                                                           |
| Сборка пакетов | **Нет шага сборки для внутренних пакетов** — `exports` указывает на `src/index.ts`, исполнение через `tsx`/vitest | Убирает проблему порядка сборки в монорепо целиком. Бандлится только то, что уезжает в прод (CLI, приложение).                                                                                                                           |
| Схемы          | zod 4 как единственная декларация → типы + рантайм-валидация + JSON Schema через `z.toJSONSchema()`               | Одна декларация вместо трёх. Structured output к Claude API получает схему из того же источника, что и валидатор.                                                                                                                        |
| API (фаза 1)   | Fastify, модульный монолит                                                                                        | Легче NestJS, без DI-магии. Один процесс до фазы 3.                                                                                                                                                                                      |
| БД             | PostgreSQL 18 + Drizzle                                                                                           | JSONB для снапшотов StyleSpec — первого класса. Миграции читаемы глазами.                                                                                                                                                                |
| Очередь        | **pg-boss**, не BullMQ                                                                                            | Очередь в той же Postgres → нет Redis. Минус один сервис в проде, в бэкапе и в мониторинге. Ёмкости хватает до тысяч генераций в сутки; на фазе 3 пересмотреть.                                                                          |
| PDF            | Playwright (Chromium), HTML→CSS→PDF                                                                               | Документ верстается обычным HTML — тот же движок, что и в вебе, значит превью PDF в интерфейсе бесплатно.                                                                                                                                |
| Тесты          | Vitest, два проекта: `unit` и `golden`                                                                            | Голден-сет отделён: он медленный и гейтит мерж отдельно.                                                                                                                                                                                 |
| Прод           | Docker Compose на одной VPS в РФ-контуре                                                                          | 152-ФЗ. Kubernetes не нужен до фазы 3.                                                                                                                                                                                                   |

## Структура

```
packages/core       общие типы, confidence, ошибки, единицы, учёт стоимости
packages/kb         справочники JSON + zod-схемы + загрузчик
packages/stylespec  схема StyleSpec, версионирование, миграции снапшотов
packages/vision     Claude API → VisionReport + контент-кэш
packages/assembly   POM · Construction · BOM · Labels · TechSequence (чистые функции)
packages/flats      параметрический SVG-рендерер
packages/docgen     StyleSpec → HTML → PDF, экспорт по ролям
apps/cli            станок фазы 0
apps/web            лендинг (фаза 1а) + приложение (фаза 1б)
apps/admin          concierge-админка
golden/             эталонные фото + ожидаемые StyleSpec + снапшоты
```

Правило зависимостей — строго вниз: `core ← kb ← stylespec ← {vision, assembly} ← {flats, docgen} ← apps`. Циклы запрещены.

## Последствия

- Внутренние пакеты не публикуются и не собираются — потребитель обязан уметь TypeScript. Для наших приложений это так.
- Postgres несёт и данные, и очередь. При росте нагрузки очередь съедает I/O БД — сигнал к выносу, порог смотрим на фазе 3.

## Когда пересматривать

TS 7 — когда `typescript-eslint` его поддержит. pg-boss — когда p95 ожидания в очереди превысит 30 с. Монолит — когда время деплоя превысит 10 мин.

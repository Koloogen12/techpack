# ADR-0001 — StyleSpec: схема, версионирование, миграции

**Статус:** принято · 2026-08-25

## Контекст

`StyleSpec` — единственный источник правды об изделии (`TECH-REQUIREMENTS-PIPELINE.md` §0.1). Флэты, таблицы, PDF — его проекции. Всё, что продукт умеет, упирается в качество этой схемы; всё, что он будет уметь через год, — тоже.

## Решение

**1. Одна декларация — zod.** Схема пишется на zod, из неё выводятся TypeScript-типы, рантайм-валидатор и JSON Schema (для structured output Claude API и для внешней документации). Ручного дублирования нет.

**2. Каждое значимое значение — обёртка, а не примитив.**

```ts
type Tracked<T> = {
  value: T;
  confidence:
    'fit_confirmed' | 'user_input' | 'estimated_from_photo' | 'default_from_base' | 'assumption';
  source: string; // откуда именно: 'pom_templates/tshirt#T03', 'vision:v1', 'user:wizard.q2'
  note?: string; // человеческим языком: «уточнить по образцу»
};
```

Тип `Tracked<T>` делает принцип §1.3 `CTO-SPEC.md` («значение без источника не компилируется») буквальным: забыть источник нельзя — не соберётся. Это дешевле любой ревизии.

**3. Иерархия доверия** (по убыванию, `ux/02` Приложение А): `fit_confirmed` > `user_input` > `estimated_from_photo` > `default_from_base` > `assumption`. Слияние двух источников на одно поле всегда выигрывает более высокий ранг; равный ранг — выигрывает более поздний по времени. Правило реализовано один раз в `core`, а не в каждом движке.

**4. Версионирование.** Поле `spec_version` (semver). Снапшот в БД хранится как есть, никогда не переписывается на месте. Чтение снапшота старой версии проходит через цепочку миграций `migrations/0.1→0.2→…`, каждая — чистая функция с тестом на реальном снапшоте. Ломающее изменение схемы без миграции блокирует мерж.

**5. Что НЕ хранится в StyleSpec:** SVG, PDF, HTML, любые растровые изображения. Только ссылки на объекты в хранилище. Правило `CTO-SPEC.md` §1.1: правда никогда не живёт в картинке.

## Последствия

- Схема заметно многословнее «плоского» JSON — это осознанная цена честности значений.
- Рендеры получают на вход `Tracked<T>` и обязаны решать, показывать ли статус. Забыть отрисовать статус можно, но забыть его _передать_ — нельзя.

## Когда пересматривать

При добавлении категории вне трикотажного ядра — проверить, что шаблон точек не потребовал ломающего изменения.

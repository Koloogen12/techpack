## 2. Справочник фурнитуры

### Молнии

Тип зуба: витая (T3–T8) — карманы/платья/потайные; тракторная — куртки/худи; металл — джинсы/кожа. Размер № = ширина звена мм: **#3** (~4,5) карманы/гульфик; **#5** (~6) куртки/худи; **#8/#10** верхняя/спец. Разъёмность: closed-end / open-end / two-way. Слайдер: автолок/полуавтомат/галантерейный. Бренды: YKK (в 2–4× дороже), SBS, KCC, riri; в техпаке — «YKK или аналог по согласованию».

### Пуговицы — система ligne

**1L = 0,635 мм.** 14L=9 мм (воротник рубашки) · 16L=10 · 18L=11,5 · 20L=12,5 (блузы) · 24L=15 (брюки) · 28L=18 (рукав пиджака) · 32L=20 (борт пиджака, джинсовая 17–20 мм) · 36–40L=23–25 (пальто).

### Кнопки, люверсы, шнуры, резинки

Кнопки альфа/омега 9,5/12,5/15/17 мм; джинсовые пробивные 15–20. Люверсы 4/5/6/8/10 мм (худи 5–6). Шнуры круглые 4–6 мм, плоские 10–15; наконечники, стопперы. Резинки 10–60 мм (джоггеры 30–40, бельё 10–15). Велкро 20/25/50. Косая бейка 15/18/25.

### Нитки

50/2 — тонкие ткани · **40/2 — универсальная** · 20/2–20/3 — отделочная (деним) · армированные 35ЛЛ/44ЛХ/45ЛЛ · 70ЛЛ — деним/спец · текстурированные — петля оверлока по трикотажу.

### Клеевые прокладки

Флизелин (нетканый, 25–100 г/м²) — планки, лёгкие детали · дублерин (тканый/трикотажный, 40–250) — воротники, борта, пояса · паутинка (лента 10–30 мм) — подгибки · долевик/кромка (10–15 мм) — плечевые, проймы.

### 3.3. Как нормирует фабрика

Норма = площадь лекал + межлекальные выпады (≈80% потерь) + потери настила ([busel](http://www.busel.org/texts/cat5vk/id5awrfee.htm), [Инфоурок](https://infourok.ru/raschyot-norm-rashoda-materiala-analiz-racionalnoy-raskladki-lekal-4013945.html)). Типовые % выпадов: брюки 5–6%, платья 12–15%, плащ ~20% ([studfile](https://studfile.net/preview/10100843/page:11/)). **Вывод:** SpecForm даёт предварительный расход с пометкой «уточняется фабрикой по раскладке»; финальную норму считает фабрика.

## 4. Словарь RU↔EN

кулирка = single jersey · футер 3-нитка с начёсом = brushed fleece · кашкорсе = 2×2 rib · рибана = 1×1 rib · плащевка = shell fabric · подкладка = lining · утеплитель = insulation/padding · дублерин/флизелин = woven/non-woven fusible · молния разъёмная тракторная №5 = #5 molded open-end zipper · блочка = eyelet · стоппер = cord lock · кнопка = snap · армированные нитки = core-spun thread · расход = consumption/yield · раскладка = marker · межлекальные выпады = marker waste · вшивной ярлык = care label · навесной = hangtag · тон в тон = DTM

## Gaps

Размерные системы фурнитуры — отраслевой стандарт без RU-первоисточника; расход футболки зависит от ширины полотна (хранить оба диапазона с условиями).

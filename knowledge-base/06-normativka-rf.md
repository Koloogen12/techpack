# Блок 6. Нормативные требования РФ (маркировка, сертификация, ярлыки)

## 1. ТР ТС 017/2011 «О безопасности продукции лёгкой промышленности»

Текст: [docs.cntd.ru/902320564](http://docs.cntd.ru/document/902320564).

| Слой                         | Что входит                                                                           | Подтверждение соответствия                        |
| ---------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------- |
| 1-й (прямой контакт с кожей) | нательное и постельное бельё, корсетные, купальники, носки 1-го слоя, полотенца      | **Сертификация** (обязательный сертификат)        |
| 2-й (ограниченный контакт)   | платья, блузки, рубашки, брюки, юбки, костюмы без подкладки, свитеры, головные уборы | **Декларирование** (1д/3д/6д серия; 2д/4д партия) |
| 3-й (поверх 2-го)            | пальто, куртки, плащи, костюмы на подкладке                                          | **Декларирование**                                |

Детская одежда — **ТР ТС 007/2011**: бельё/1-й слой до 3 лет — СГР + декларация; 1-й слой детский — сертификация; 2–3-й — декларирование ([НЦС](https://nccenter.ru/uslugi-po-otraslyam/sertifikatsiya-detskikh-tovarov/sertifikatsiya-detskoy-odezhdy/), [rctest](https://www.rctest.ru/sertifikaciya-produkcii/tekhnicheskie-reglamenty/tr-ts-007-2011/)).

Нормируемые показатели (лаборатория, не из фото): гигроскопичность, воздухопроницаемость, формальдегид, стойкость окраски, электризуемость. ⚠️ Точные пределы — приложения 2–3 регламента (gap). Источники: [IFCG](https://www.ifcg.ru/services/special/certification-clothing-tr-cu-017-2011/), [Гортест](https://gortestsibir.ru/deklaratsiya-sootvetstviya-tr-ts-017-2011/).

**Роль техпака:** указать слой изделия → форма подтверждения; поле «№ декларации» — заглушка (появляется после сертификации).

## 2. Обязательные реквизиты маркировки (ст. 9 ТР ТС 017)

([Novotest — ст. 9](https://www.novotest.ru/tr-ts/017-2011/st-9/), [sudact](https://sudact.ru/law/reshenie-komissii-tamozhennogo-soiuza-ot-09122011-n_23/tr-ts-0172011/statia-9/))

1. Наименование продукции («Куртка женская»)
2. Страна изготовления
3. Изготовитель: наименование + юр. адрес
4. Импортёр/уполномоченное лицо (для импорта)
5. Размер
6. Состав сырья (% по волокнам, по убыванию)
7. Товарный знак
8. Дата изготовления (месяц, год)
9. Символы ухода (ГОСТ ISO 3758)
10. Знак **ЕАС**

На русском языке; на изделие/этикетку/ярлык/упаковку.

## 3. ГОСТ 10581-91 — носители маркировки

([docs.cntd](http://docs.cntd.ru/document/901711448)) Виды: товарный ярлык (навесной/пришивной), вшивная лента с товарным знаком, контрольная лента (размер/рост), упаковочный ярлык. Реквизиты товарного ярлыка: товарный знак, изготовитель+адрес, наименование, НД (ГОСТ/ТУ), артикул, модель, размер/рост, сорт, дата. Применяется добровольно, но фабрики ориентируются как на отраслевой стандарт.

## 4. Символы ухода — ГОСТ ISO 3758-2014

([docs.cntd](http://docs.cntd.ru/document/1200117512), [ГАРАНТ](https://base.garant.ru/71244944/))

**Порядок 5 символов: стирка → отбеливание → сушка (барабанная, естественная) → глажение → проф. чистка.**

| Группа             | Символ          | Варианты                                                                                         |
| ------------------ | --------------- | ------------------------------------------------------------------------------------------------ |
| Стирка             | таз             | t°: 95/70/60/50/40/30; рука = ручная ≤40°; 1 черта = деликатная; 2 = особо; перечёркнут = нельзя |
| Отбеливание        | треугольник     | пустой = любой; 2 линии = только кислородный; перечёркнут = нельзя                               |
| Барабанная сушка   | круг в квадрате | 1 точка ≤60°, 2 ≤80°; перечёркнут = нельзя                                                       |
| Естественная сушка | квадрат         | вертикали = вертикальная; горизонталь = разложив; косая = в тени                                 |
| Глажение           | утюг            | 1 точка ≤110°, 2 ≤150°, 3 ≤200°; перечёркнут = нельзя                                            |
| Проф. чистка       | круг            | P = перхлорэтилен, F = углеводороды, W = аква; черта = щадящая                                   |

**Дефолт-генерация символов по материалу**: хлопковый трикотаж → 30–40° деликатная, без хлора, без барабана, утюг 150°, без химчистки (типовое; редактируемо).

## 5. «Честный знак» (DataMatrix)

- Волны охвата: 2021 — верхняя одежда, кожа, трикотажные блузки, постельное; 04.2024 (ПП № 883) — рубашки, костюмы, брюки, платья, свитеры, спорткостюмы; **с 01.03.2025 — +30 позиций** (бельё, майки, носки, детское) — фактически к 2026 почти вся одежда. Источники: [markirovka.ru — 3-я волна](https://markirovka.ru/community/shoes-and-clothes/rasshirenie-perechnya-tovarov-legkoy-promyshlennosti-mart-2025), [честныйзнак.рф — легпром](https://честныйзнак.рф/business/projects/light_industry/), [Контур](https://kontur.ru/markirovka/spravka/48063-markirovka_legkoy_promyshlennosti).
- Пайплайн бренда: УКЭП + регистрация в ГИС МТ → GTIN (ГС1 РУС / Нацкаталог) → **карточка товара** (ТН ВЭД, наименование, товарный знак, состав, цвет, **размер**, пол/возраст, страна, фото) → заказ кодов (GS1 DataMatrix) → нанесение → ввод в оборот → УПД через ЭДО. [getmark — GTIN](https://getmark.ru/blog/o-markirovke/kak-poluchit-gtin-dlya-odezhdy-proizvoditelyu-importeru-kak-zakazat/), [sberbusiness — Нацкаталог](https://sberbusiness.live/publications/nacionalnyj-katalog-chestnyj-znak).
- **Следствие для SpecForm:** каждая размер-цвет-комбинация = отдельный GTIN → техпак выдаёт **SKU-матрицу (артикул × цвет × размер)** + атрибуты карточки Нацкаталога (на 90% совпадают с реквизитами ярлыка).

## 6. Шаблон страницы Labels & Packaging (РФ)

**6.1. Вшивной ярлык состава/ухода (care label)** — обязательный: сатин/нейлон, несмываемая печать. Поля: изготовитель + юр. адрес | страна | состав % | размер (рост/Ог/Об) | дата (ММ.ГГГГ) | ЕАС | 5 символов ухода по порядку. Placement: левый боковой шов, 10–15 см от низа.

**6.2. Брендовый вшивной ярлык:** лого + размер; середина горловины спинки / пояс сзади; жаккард/сатин.

**6.3. Размерник:** RU (44–58/рост) + INT (S–XL); отдельный или совмещён.

**6.4. Навесной ярлык (hangtag):** картон; бренд, наименование, артикул, состав, размер, цвет, изготовитель+адрес, **EAN-13 (GTIN) + DataMatrix ЧЗ**, ЕАС, цена (опц.); крепление и точка крепления.

**6.5. Упаковка:** индивидуальный пакет (ПВД/зип, мкм), стикер (артикул/размер/цвет/штрихкод), упаковочный ярлык на короб по ГОСТ 10581.

**Генерирует алгоритм:** макеты ярлыков с плейсхолдерами (данные юрлица — из профиля бренда), таблица placement, SKU-матрица с GTIN-плейсхолдерами. **Не генерирует:** результаты испытаний, № декларации (поле-заглушка).

## Gaps

1. Пределы показателей ТР ТС 017 (прил. 2–3) — сверить по docs.cntd.
2. Точный перечень ТН ВЭД под ЧЗ — ПП № 883 + честныйзнак.рф.
3. Цена кода ЧЗ (~60 коп.) — не верифицирована.

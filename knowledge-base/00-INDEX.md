## 10 ключевых выводов для архитектуры пайплайна

1. **ГОСТ 12807-2003 включает ISO 4915/4916 как идентичные приложения** — коды стежков (301, 401, 406, 504, 514) и швов (1.01.01/301) едины для фабрики РФ и мирового техпака. Один внутренний словарь кодов покрывает оба рынка.
2. **Абсолютные сантиметры с фото получить нельзя** (монокулярная неоднозначность масштаба). Рабочая стратегия: категория → keypoints → безразмерные пропорции с фото → якорь из базового размера, названного пользователем (сетка тела + ease-дефолт) → клэмп в правдоподобные диапазоны. Опциональные усилители: предмет-референс в кадре, один ручной замер, LiDAR (~2% ошибки).
3. **Каждое значение получает confidence-флаг**: `measured / estimated-from-photo / default-from-base / assumption`. Невидимые с фото параметры (внутренняя обработка, клеевые прокладки, состав ткани, GSM, припуски) — всегда дефолт + флаг + «уточнить по образцу».
4. **Дефолтные узлы — только под тройку машин «универсалка + оверлок + распошив»** (+петельная/пуговичная, утюг). Узлы под спецмашины (двухигольная, флэтлок, карманный автомат, лазер) — флаг «требует спецоборудования, подтвердите у фабрики» + альтернативный узел под базовый парк.
5. **РФ-комплект шире западного tech pack**: фабрика ждёт ещё лекала с градацией, раскладку, расчёт расхода. Продукт эти артефакты не генерирует из фото — в документе честные поля-заглушки «предоставляется конструктором» + предварительный расход с пометкой «уточняется фабрикой по раскладке».
6. **Табель мер с допусками — главный документ приёмки** (по нему работает ОТК). Полнота POM с допусками = ядро ценности.
7. **Модульность под цех**: каждый раздел — отдельный лист/файл, потому что табель мер идёт в ОТК, спецификация — закройщику, расчётник — снабжению. Экспорт по ролям — фича, которую не имеет ни один конкурент.
8. **Терминология — двуязычная**: фабрика говорит «конфекционная карта / табель мер / техописание», мир — «BOM / POM / construction». ГОСТ-бланки имитировать не нужно — нужен полный комплект на языке технолога.
9. **SKU-матрица (артикул × цвет × размер) с плейсхолдерами GTIN** — мост к «Честному знаку»: атрибуты карточки Нацкаталога на 90% совпадают с реквизитами ярлыка по ТР ТС 017.
10. **Метрика качества продукта** = чек-лист «идеальный техпак глазами технолога» (07, §6): комплектность 8/8, однозначность, POM+допуски, узлы под парк машин, материалы с артикулами, расчётопригодность (расход + операции → цена), версионность.

## Следующий шаг

На этой базе собираются **технические требования к пайплайну генерации**: (1) схема данных (01), (2) этапы пайплайна: классификация фото → keypoints/пропорции → категориальный шаблон (POM+узлы+материалы) → пользовательские вводные (базовый размер, fit, трикотаж/ткань) → расчёт значений → confidence-флаги → сборка документа по ролям → экспорт PDF/SVG. Ограничение сверху: РФ-парк машин (07) и «видно/не видно» (04, §7).

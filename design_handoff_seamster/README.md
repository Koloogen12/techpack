# Handoff: Seamster — веб-приложение генерации техпаков

## Обзор
Seamster — инструмент, который превращает фото/эскиз изделия в производственный технический пакет (техпак): чертёж, замеры с градацией, материалы (BOM), конструкция, ярлыки, версии, экспорт в PDF. Прототип покрывает полный путь пользователя: вход → домашняя → мастер создания → экран генерации → рабочий документ (8 разделов) → библиотека бренда → тариф → отправка на просчёт фабрикам.

## О файлах в архиве
Файлы бандла — **дизайн-референсы, собранные в HTML** (Design Component). Это прототип, показывающий целевой вид и поведение, а НЕ production-код для копирования. Задача разработки — **воссоздать эти экраны в целевом стеке** (React/Vue/Svelte и т.д.) по паттернам вашей кодовой базы. Если стек ещё не выбран — рекомендован React + любой CSS-in-JS/tailwind: вся стилистика в прототипе инлайновая и переносится 1:1.

- `Seamster - Воркспейс.dc.html` — весь прототип: разметка (внутри `<x-dc>`) + логика (класс `Component`, обычный JS, состояние/обработчики). Открывается в браузере вместе с `support.js` (рантайм, в реализацию не переносится).
- `UI-SPEC-app.md` — исходный PRD (карта продукта, сценарии, критерии приёмки).
- `assets/` — битмапы из дизайна (см. «Ассеты»).

## Фиделити
**High-fidelity.** Цвета, типографика, отступы, радиусы, тексты и состояния — финальные, воспроизводить точно. Все значения — в этом README и в инлайн-стилях прототипа (они являются спекой). Не округлять к 4/8px-сетке: нестандартные значения (13px, 27px, 9.7px…) — намеренные.

### Типографика
- **Sora** (Google Fonts) 400/600/700 — UI: заголовки, кнопки, таблицы. Кикеры: 8.3–10px, letter-spacing 1.1–1.6px, uppercase, вес 600–700.
- **Inter** 300 — **значения данных** в документе (12px, светлый, часто data-red).
- **JetBrains Mono** 400/500 — коды, артикулы, числа таблиц (9.7–10.5px), `font-variant-numeric: tabular-nums`.
- Базовые размеры: заголовок панели 15.5/700, заголовок дока 16.6/700, хиро 40–44/700 (letter-spacing −1px), строка таблицы 12/400, подписи 10–10.5.

### Геометрия
- Радиусы: сайдбар/крупные панели 18, карточка документа 14, рейл-флайаут 16, блоки документа 10, меню/дропдауны 12, кнопки 9–12, чипы 8–9, пилюли 999.
- Тени: документ `0 20px 48px rgba(14,14,14,.1), 0 4px 14px rgba(14,14,14,.06)`; меню `0 18px 44px rgba(0,0,0,.18)`; плавающие пилюли `0 16px 42px rgba(0,0,0,.1) + inset 0 1px 0 1px rgba(255,255,255,.8)`.
- Фон канваса — точечная миллиметровка: `radial-gradient(rgba(14,14,14,.075) 1px, transparent 1.2px)`, size `26px 26px`, offset `13px 13px`.
- Стекло сайдбара: `rgba(255,255,255,.48)` + бордер `rgba(14,14,14,.08)` + `inset 0 1px 0 1px rgba(255,255,255,.7)`.
- Сетка приложения: `300px | 1fr | 69px` (сайдбар · канвас · тулбар), высота `100vh − 34px` (промо-бар). Документ: max-width 1030, рейл слева 74px от него.

### Анимации
- `sfup` — появление панелей/меню: `translateY(8px)→0 + fade`, 140–200ms ease.
- `sfpulse` — пульс точки/зоны: box-shadow ring 0→14px prozrачность, 1.2s infinite.
- `sffloat` — левитация карточек генерации: `translateY(0→−7px→0)`, 3.2s ease-in-out infinite (+ индивидуальный `rotate(−3.5…+3deg)` и задержка).
- `sfshimmer` — скелетоны: градиентная полоса, 1.4s linear infinite.
- Печатная машинка: посимвольно ~28ms/символ, курсор — `▮` цвета ink, мигание 1s.
- Тумблеры/чипы: transition 160ms ease.

## Экраны

### 1. Вход (`screen: auth`)
Центр канваса, карточка 360px: лого-квадрат 44px (ink, радиус 14, глиф слоёв), «Seamster · бета», кнопка «Войти с Яндекс ID» (белая, красная «Я»), разделитель «или», поля Почта + Пароль (фокус: бордер ink), «Забыли?», чёрная CTA «Войти», «Нет аккаунта? Регистрация», внизу Приватность · Условия. Ошибка входа: красный текст под полем. «Пропустить (демо)» — ссылка. Выход из аккаунт-меню возвращает сюда.

### 2. Домашняя (`section: home`, стартовая после входа)
Кикер «SPECFORM OS · БЕТА», хиро «От фото — к производству, с ясностью» (44/700), подстрока, чёрная CTA «Создать техпак» + 4 быстрых действия (чертёж/3D-рендер/принт/примерка — открывают панели режимов). Карточка «Продолжить: Структурный жакет» (последний пак). Подсказка новичку «начните с 1–2 фото» + пример-пак. Ссылка «Все паки списком →».

### 3. Все паки (`section: packs`)
Поиск (по названию и артикулу), фильтры-чипы по статусу (Все/Готов/Черновик/На просчёте), сетка карточек: превью (битмап), название, артикул-моно, статус-чип, версия, ⋮-меню (переименовать/дублировать/удалить с undo-тостом). Плитка «+ Новый техпак». Пустые состояния: новичок («Создайте первый техпак», шаги 1-2-3) и пустой поиск («ничего не нашлось» + Сбросить).

### 4. Мастер создания (2 шага, `screen: wizard`)
Прогресс-полоса сверху (33%/66%). Шаг 1 «Фото или эскиз»: дропзона (клик добавляет файл, «N из 6»), карточки файлов с крестиком; блок «Повысить точность» (свёрнут): чип состояния «сейчас ±2 см»→«±1 см активно» (зелёный), карточка «Фото с эталоном размера» (А4/карта, схема, состояние «эталон найден: А4»), «Один ручной замер» (инпут «длина по спинке», плейсхолдер 66). Шаг 2 «Пять вопросов»: карточки-вопросы с чипами, у 01 и 04 бейдж «определили по фото» (авто-угадывание), 05 совмещает размерный ряд + тираж (тираж даёт живую подсказку). «Закрыть» на шаге ≥2 → поповер «Черновик сохранится». CTA «Запустить генерацию».

### 5. Экран генерации (`screen: generating`) — ключевой вау-момент
Полноэкранный, поверх промо-бар скрыт. Сверху: вехи АНАЛИЗ → ГЕНЕРАЦИЯ → СБОРКА (активная — жирная + пульс-точка, пройденная — зелёная галочка), общий прогрессбар (2px, ink), процент-моно, чип «Процесс техпака», справа «✕ Отменить». Центр: карточки результатов **появляются последовательно** (Референс 1 → Технический чертёж ~40% → Рендер в 3 видах ~80%), каждая: белая, радиус 14, тень, подпись-кикер снизу, лёгкий поворот, **левитация** (sffloat), влёт снизу (sfup 500ms); в конце ряда пульсирует метка «Пайплайн работает…». Низ: сменяемая строка статуса («Отделяем крой от стилистического шума…»), таймер «N:NN прошло». Правая панель 312px «Добавить детали»: поля бренд/название/сезон/база/категория/описание/материалы, «Подтвердить детали →», красный «✕ Стоп»; сворачивается → сверху чёрная «+ Добавить детали, пока ждёте». При 100% — CTA «Открыть техпак». Ошибка (имитация): карточка «Не получилось построить чертёж» + «Заменить фото» / «Повторить бесплатно» (лимит не списан).

### 6. Документ техпака (`screen: doc`, 8 разделов)
Каркас: чёрная планка вкладок (открытые паки + «Новый пак»), шапка (кикер «Текущий техпак», название + статус-чип, артикул-моно · версия · обновлён · «сохранено» зелёным; кнопка «Предположения: N» (красная рамка, фильтр), тумблер Pro-режим, чёрная «Экспорт», ⋮-меню), слева вертикальный **рейл**: свёрнут — пилюля с дашами (активный 18px ink), по ховеру раскрывается в флайаут 212px «01. Обзор / стиль и визуал…» (активный: планка 2.5px + жирный; ховер: жирный + фон), пин фиксирует. Справа плавающий тулбар-пилюля (34px кнопки, тултипы).

Разделы (у каждого шапка-кикер на `rgba(14,14,14,.04)`):
1. **Обзор** — шапка-таблица паспорта (БРЕНД/АРТИКУЛ/ТКАНЬ/ДАТА · СЕЗОН/ОПИСАНИЕ/РАЗМЕР; лейблы-кикеры + значения Inter 300 data-red), полоса «ТЕХНИЧЕСКИЙ ПАКЕТ», галерея (табы Чертёж/Фото, зум), «Общая информация» 2 колонки со статус-точками, **виджет готовности к производству** (процент + 6 пунктов-ссылок с состояниями ✓/⚠/—), баннер предположений (красный) → при 0 зелёный «всё подтверждено».
2. **Чертёж** — виды (Все/Перед/Бок/Спинка — зум-кадрирование битмапа), слои-чипы (Контур/Швы/Строчки/Фурнитура/Выноски), **выноски-номера** на чертеже (кружки ink, цифры штрихами) → клик открывает узел в Конструкции; подсказка «геометрия правится только через данные».
3. **Замеры** — таблица POM: Код-моно · Точка (+моно-хинт) · База M (инлайн-**инпут**: правка → зелёная рамка, статус «указано вами», тост «Чертёж обновлён», пульс мини-схемы) · Допуск · XS/S/L/XL · [Δ град. в Pro] · Статус-точка+лейбл. Клик по строке → **панель деталей**: крупное значение, «откуда это число», как мерить, инпут допуска per-строка, «Подтвердить по образцу», «Сбросить к рассчитанному», мини-схема. Футер-легенда 4 статусов. «Сбросить к рассчитанным», «Пересчитать градацию». Фильтр «только предположения».
4. **Материалы (BOM)** — группы (Полотно/Фурнитура/Нитки и прокладки/Упаковка/Добавлено из библиотеки), колонки Код·Позиция·Состав·Цвет (свотч+Pantone)·Расход·Статус; колорвеи-чипы (Чёрный/Экрю — перекрашивают свотчи полотна и Pantone); «+ добавить из библиотеки» → меню материалов; себестоимость: «≈1 240 ₽ материалы + 38 мин работы · тираж 100».
5. **Конструкция** — нумерованные узлы (номер = выноска на чертеже, выбранный — ink-кружок): зона-кикер, название, описание; в Pro: чипы ГОСТ-шва, SPI (тултип), машина; флаг «требует спецоборудования» + «заменить на узел для базового цеха» (меняет узел, чертёж, техпоследовательность). В Pro — таблица техпоследовательности (7 операций: №·операция·машина·время).
6. **Ярлыки** — составник (символы ухода по материалу, юрданные из библиотеки), размерник M·RU 46, навесной ярлык (превью 45×70: [БРЕНД]→имя из библиотеки, флаг «заполните профиль бренда» → кнопка в Библиотеку), SKU-матрица 5 позиций с GTIN-плейсхолдерами + «как устроено» (тултип про Честный знак).
7. **Версии** — таймлайн v1.0 → Примерка №1 → v1.1; таблица фактов: «по спеке · факт (инпут) · Δ · в допуске да/нет» (живой пересчёт, вне допуска — красный чип); «Применить в новую версию» → в Замеры.
8. **Экспорт** — 4 карточки (PDF полный / PDF по ролям с мультивыбором чипов-ролей / SVG послойный / **Отправить на просчёт** — зелёная); язык PDF (Русский/English/中文); живое превью первой страницы PDF; история выгрузок. «Отправить на просчёт» → выбор из 3 фабрик чекбоксами → статус пака «На просчёте» в сайдбаре/карточках + уведомление.

Печатная машинка: при открытии пака из генерации описание в паспорте, значения общей информации и описания узлов «допечатываются ИИ» посимвольно с курсором ▮, последовательно по модулям.

### 7. Сайдбар (постоянный)
Шапка: лого + «Рабочая область» (клик → домашняя), колокольчик уведомлений (красная точка; панель: 3 уведомления-ссылки), кнопка сворачивания (сворачивает до бургера). Счётчик «Всего: N коллекций, N паков» — живой. Секции: **Быстрые действия** (шеврон раскрывает 4 пункта → панели режимов), **Коллекции** (раскрытие: паки внутри, «добавить: …», «+ Новая коллекция» → инлайн-форма имени), **Одиночные паки** (карточки: превью, имя, саб, статус-чип, ⋮-меню CRUD; черновик открывает мастер с его шага; «На просчёте» — статус). Ниже: Библиотека бренда (флаг «заполнить»/«готово»), Тариф и кредиты (2/3). Футер: «Баланс генераций 2 из 3», чёрная «Увеличить лимит», карточка аккаунта → меню вверх (баланс+прогресс, «Пригласить друга +1», «Купить генерации», «Управление тарифом», «База знаний», «Аккаунт», «Язык · Русский», красный «Выйти»).

### 8. Панели режимов (правый тулбар, 312px оверлей справа)
5 режимов: Новый техпак (дропзона + референсы 0/4 + выбор модели + CTA), Техчертёж (дропзона → «Построить чертёж» → открывает раздел Чертёж), 3D-рендер (ракурсы), Принт (описание + зона размещения, CTA активна после ввода), Примерка (фото модели + размер). У недоступных CTA — подсказка почему; дисклеймер «результат — черновик, не норма».

### 9. Библиотека бренда (`section: library`)
4 блока: **Материалы** (список + «Добавить материал» → инлайн-форма: название, состав/плотность, 5 свотчей, Pantone; валидация имени), **Размерная сетка** (загрузка → «ваша сетка: 6 размеров — перекрывает ГОСТ»), **Юрданные** (форма 3 поля → каскад: ярлыки, составник, чек-лист готовности, флаг в сайдбаре), **Логотип** (превью + удалить). Пустые состояния всех блоков — с пользой и CTA.

### 10. Тариф и кредиты (`section: billing`)
Крупный баланс «2 из 3» + прогресс, история списаний (успех −1, ошибка 0 ₽ зелёным), сравнение Бесплатный/Студия, «Перейти на Студию» → лист ожидания, зелёный блок «Производство через платформу = безлимит генераций».

## Взаимодействия и поведение (сквозные)
- **Тосты**: чёрная пилюля снизу по центру, зелёная точка, 2.2s, есть вариант с «Отменить» (undo удаления пака).
- **Тултипы терминов**: пунктирное подчёркивание, по ховеру чёрная карточка ≤240px (градация, допуск, SPI, расход, GTIN…). Тултипы иконок тулбара — то же.
- **Счётчик предположений** всегда вычисляется из данных (POM + BOM); подтверждение значения уменьшает его везде (кнопка шапки, баннер, чек-лист).
- **Скелетоны**: шиммер документа при открытии пака (600ms), «Обновить» у превью PDF.
- **Фокус**: инпуты — бордер ink; ховер строк таблиц `rgba(14,14,14,.02-.03)`.
- **Промо-бар** (34px, зелёный) скрыт на рабочих экранах (документ, мастер, генерация).
- Правки замеров/допусков живут в состоянии пака; «Сбросить» возвращает рассчитанные.

## Модель состояния (ориентир для реализации)
- `auth` (вход/демо), `screen: home|packs|doc|wizard|generating|library|billing`, `section` внутри дока (8), `tab` открытых паков.
- Пак: `{id, name, article, status: draft|running|done|quoting, step, thumb, version}`.
- Данные дока: `vals{code}`, `tols{code}`, `confirmed{code}` (перекрытия поверх расчётных POM), `colorway`, `bomExtra[]`, `swappedNode`, `facts{}` (примерки).
- Библиотека: `materials[]`, `legal{company,inn,address}`, `sizeGrid`, `logo` — каскадно влияют на ярлыки/чек-лист/BOM-меню.
- `collections[{name, packIds}]`; `notifications[]`; `credits {used, total}`.
- Генерация: `genStep 0-5`, `genPct`, карточки по порогам 0/40/80%, `genErr`, таймер.
- Pro-режим — глобальный флаг, только раскрывает плотность (Δ градации, ГОСТ/SPI, техпоследовательность), экранов не добавляет.

## Критерии приёмки (из PRD, обязательны)
- Новичок доходит от фото до PDF без единого незнакомого слова (термины объясняются тултипами).
- Любое значение отвечает на «откуда это число» в один ховер/клик.
- Правка замера видимо меняет чертёж ≤1 сек (в прототипе — имитация пульсом).
- Pro-режим не добавляет экранов — только плотность.
- Ни одного пустого состояния без действия; ни одного статуса без следующего шага.
- Зелёный на экране = только «подтверждено/принято/готово»; красный = данные изделия и предположения/ошибки; блюр — только вне рабочих данных.

## Чего в прототипе нет (границы)
- Реального бэкенда/ИИ: генерация, тексты, пересчёты — сценарные имитации.
- Послойного SVG чертежа (слои-чипы переключают только состояние; чертёж — битмап).
- Контента 3D-рендера/примерки/принта (только флоу запуска).
- Адаптива ниже 1024px и мобильной версии.
- Реальных файлов PDF (экспорт — имитация с превью).


## Обновление 2 — расширение функционала (11 улучшений)

### Продуктовые
1. **Ссылка для фабрики** — Экспорт → стрип «Ссылка для фабрики» (copy + «Открыть как фабрика»), дублируется в меню ⋮ документа. Экран `factory`: read-only документ (шапка, чертёж, замеры), языки RU/EN/ZH (словарь `FACTORY_I18N` — заголовки + названия точек POM), «Задать вопрос» у строки → чип «вопрос фабрики» в основном документе (state `factoryQuestions`, текст по title-ховеру).
2. **История значения** — панель деталей замера, блок «История»: исходная запись «ИИ · источник → значение», далее правки «вы · было → стало», допуски, подтверждения, сбросы.
3. **Импорт техпака** — мастер, вкладка «Импорт PDF · Excel» (+ ссылка с домашней). Дропзона → отчёт распознавания: замеры ok / BOM warn / градация info → «Создать пак из импорта», лимит не списывается.
4. **Взять за основу** — меню ⋮ пака: мастер с шага вопросов, бейдж «На основе: <имя>», предзаполненные ответы.

### UX
5. **Diff версий** — «Версии», карточка «Что изменилось · v1.0 → v1.1»: «код · точка · старое (зачёркнуто) → новое (зелёное) · источник» (факт примерки / правка / допуск / замена узла). Пустое состояние с подсказкой.
6. **Клавиатура в POM** — Enter/↑/↓ ходят между инпутами (`data-pomidx`), ⌘Z — откат последней правки (undo-стек `hist`, тост).
7. **Валидация здравого смысла** — `SANE`-диапазоны на точку; вне: ⚠ у названия + красное пояснение в деталях. Не блокирует ввод.
8. **См/дюймы** — тумблер в шапке замеров; конвертация таблицы/градации/допусков/деталей, ввод в in пишется в см (×2,54, до 0,1). Diff и PDF всегда в см.

### Дизайн
9. Тулбар режимов скрыт на Библиотеке и Тарифе (`toolsOn`).
10. Чертёж на Обзоре — 560px, роль обложки.
11. Черновики: силуэт-плейсхолдер категории вместо фото — сайдбар и карточки.

# Образцы полотна

Снимки выкрасов, на которые ссылаются колорвеи в анкете:

```json
"colorways": [{ "id": "navy", "name_ru": "Тёмно-синий", "swatch": "navy-even.png" }]
```

С кадра снимается цвет: hex для экрана и координаты Lab для колориста. Это
**визуальный референс, а не цветопроба** — снимок под неизвестным светом
не позволяет отличить цвет ткани от цвета лампы. Точный цвет подтверждается
лабдипом.

Два файла здесь — синтетические, не фотографии ткани. Они существуют, чтобы
показать обе ветки проверки на ровность съёмки:

| Файл             | Что показывает                                                        |
| ---------------- | --------------------------------------------------------------------- |
| `navy-even.png`  | ровный кадр с фактурой переплетения — проходит: фактура не складка      |
| `navy-fold.png`  | тот же цвет со складкой через кадр — бракуется, цвет берётся с освещённой части |

Как снимать по-настоящему: образец ровно и во весь кадр, равномерный
рассеянный свет, без вспышки и без падающей тени.
